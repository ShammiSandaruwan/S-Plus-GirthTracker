# Support Policy — GirthTracker

This support policy is written for selling GirthTracker as a downloadable digital source-code product.

---

## Included Support

A purchase includes access to:

- Source code files
- Documentation included in the repository
- Google Apps Script backend template
- Basic setup instructions
- Basic troubleshooting notes

At the seller's discretion, limited support may be provided for:

- Missing file access
- Duplicate purchase issues
- Clarification of documentation
- Obvious packaging mistakes

---

## Not Included by Default

The purchase does not include custom work such as:

- Installing Node.js or development tools on the buyer's computer
- Setting up Google accounts or Google Sheets permissions
- Deploying the app to the buyer's hosting account
- Debugging every Bluetooth caliper model
- Customizing the UI or branding
- Adding new features
- Building dashboards, reports, charts, or admin panels
- Converting the app to Android/iOS native apps
- Providing long-term maintenance
- Providing unlimited one-on-one support

## Response Time

For a small digital product, suggested response time is:

- Basic product access issue: 1–3 business days
- Documentation clarification: 2–5 business days
- Custom work inquiries: 2–5 business days

Do not promise instant support unless you are prepared to provide it.

---

## Hardware Compatibility Disclaimer

GirthTracker is designed for Bluetooth calipers that send measurements as keyboard/HID input.

Compatibility depends on the caliper model, phone/tablet, browser, operating system, language keyboard layout, and caliper output format.

The seller cannot guarantee that every Bluetooth caliper will work without adjustment.

---

## Refund Policy

Because this is a downloadable digital source-code product, refunds are not offered after download except for:

- Duplicate purchases
- File access problems that the seller cannot resolve
- Incorrect product delivery

Buyers are responsible for reading the requirements before purchase.
